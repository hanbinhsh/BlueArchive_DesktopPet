## 运行

解压 `release/BA-Desktop-Pet-0.1.22-win-x64.zip`，双击 `BA Desktop Pet.exe`。请保留解压目录内的 DLL、`resources` 等文件，不要只复制 EXE。运行不需要 Node.js、Python、.NET 或 Unity。

首次启动显示光，默认置顶。系统托盘中有粉蓝色圆环图标；如果角色被隐藏或移出视野，可从托盘恢复。

| 操作 | 效果 |
| --- | --- |
| 左键拖动角色 | 播放提起动作并移动桌宠，松手恢复待机 |
| 单击角色 | 原版咖啡厅互动，结束后恢复待机 |
| Shift＋左键拖动 | 水平旋转模型 |
| Ctrl＋左键上下拖动 | 垂直旋转模型（±90°） |
| 右键／托盘 → 垂直视角 | 向上／向下旋转 15°，或恢复水平 |
| 滚轮 | 调整角色大小（160～480 逻辑像素） |
| 右键角色／托盘图标 | 显示中文菜单 |
| 右键／托盘 → 角色／服装 | 57 个角色／服装包切换，自动保存选择 |
| 右键／托盘 → 动作 | 选择待机、互动、原地走路、胜利、换弹、编队提起 |
| 双击托盘图标 | 显示／隐藏 |
| 托盘 → 恢复默认位置与朝向 | 找回角色 |
| 托盘 → 退出 | 完全结束程序 |

拖动期间按原版资源标记循环播放提起动作，松手或取消拖动时回到待机；Shift 拖动用于水平旋转，Ctrl 拖动用于上下旋转。视角围绕角色中心旋转并自动保存。芹香新年、泳装提供四个动作；纯子两套服装各有六个动作。普拉娜使用正常比例 NPC 原版模型，提供待机、回应、微笑及两种眨眼，空闲时每 6 秒触发原版眨眼片段；原资源没有编队提起，拖动时保持待机。动作菜单中的非待机动作播放一次后自动回到待机，随时可选择“待机”中止。没有口型事件的动作维持默认嘴型，不添加自动说话或音频。角色周围的透明区域不阻挡其他窗口。隐藏时停止渲染。默认目标帧率 30 FPS；位置、大小、朝向和置顶设置自动保存到 Windows 用户数据目录中的 `blue-archive-desktop-pet/settings.json`。

## 0.1.8：面板、随机待机和桌面活动

右键角色或系统托盘，打开「角色与动作面板…」。服装按人物分组，可搜索、看缩略图并切换。右侧「▷」在桌宠上试播动作，「☆」收藏，支持只看收藏；收藏按角色服装分别保存。

「随机待机动作」与「桌面走动」默认关闭。在面板开启后，**关闭面板**才开始自动活动。随机动作约每 15 秒至 2 分钟播放一次（有少量随机变化），仅选取已验证的咖啡厅互动或普拉娜原版表情，结束回到待机。

鼠标碰到角色、拖动／旋转／缩放、右键菜单、打开面板、隐藏、休眠或切换角色时暂停自动走动。手动放置到新位置后重设活动中心。两项开关、间隔、范围、速度、收藏和位置均保存。可随时从面板关闭自动活动，或点「找回桌宠」。

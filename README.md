## 0.1.8：面板、随机待机和桌面活动

右键角色或系统托盘，打开「角色与动作面板…」。服装按人物分组，可搜索、看缩略图并切换。右侧「▷」在桌宠上试播动作，「☆」收藏，支持只看收藏；收藏按角色服装分别保存。

「随机待机动作」与「桌面走动」默认关闭。在面板开启后，**关闭面板**才开始自动活动。随机动作约每 15 秒至 2 分钟播放一次（有少量随机变化），仅选取已验证的咖啡厅互动或普拉娜原版表情，结束回到待机。

走动以当前位置为中心，沿水平方向在设定半径和当前显示器工作区域内移动；可调整半径和速度。原版走路动画循环播放，行走时朝向行进方向，停下恢复手动朝向。走动之间停留约 8～20 秒，角色没有走路动画时保持原地（例如普拉娜）。这不是应用窗口边缘攀爬或物理碰撞模拟。

鼠标碰到角色、拖动／旋转／缩放、右键菜单、打开面板、隐藏、休眠或切换角色时暂停自动走动。手动放置到新位置后重设活动中心。两项开关、间隔、范围、速度、收藏和位置均保存。可随时从面板关闭自动活动，或点「找回桌宠」。

# 0.2.0 生活质量改进

通过托盘的「角色与动作」打开设置。顶部提供当前角色、执行进度、停止播放和找回桌宠；侧栏分为角色与动作、动作组合、自动活动、外观与窗口、通用设置。角色列表和动作列表分别滚动，滚动条仅在悬停或键盘聚焦时轻量显示；搜索、分类与各页滚动位置在窗口打开期间保留。动作组合采用左侧组／条目列表、右侧步骤卡片的布局，整理操作集中在「⋯」菜单。

## 动作组合

动作条目属于当前服装，可包含普通动作和家具动作的任意有序组合。每步选择播放次数，或按实际时间循环若干秒；结束后间隔期间保持末帧。可以逐步试播，也可以试播整个组合。普通动作支持搜索、分类与批量加入。

条目可以加入多个命名组。启用多个组时按条目 ID 去重后等概率抽取；候选超过一个时避免紧接着重复同一条目。动作组合页的修改需要「保存」，「取消」恢复已保存内容，未保存离开会询问。不同服装分别保存，缺失动作明确标记并排除自动随机。

在「自动活动」开启随机动作才会自动抽取；旧版安全随机池迁为默认组，新增示例组默认不启用。日奈睡衣预置「窗边休息」：坐下一次、休息循环 20 秒、起身一次。同一套沙发或床的连续片段共用模型、骨骼和取景，不重载窗口。不同场景预加载并淡入淡出。

手动选动作、换角色或停止会取消组合。普通桌宠拖动时取消组合并提起；家具播放期间拖动只移动场景。鼠标经过不取消组合。隐藏或系统休眠时暂停动画和实际时间计数；恢复后继续。退出后不恢复执行进度。设置打开时不启动新的自动动作，当前组合可以完成，试播仍可用。

## 范围与位置

「调整走动范围」显示角色窗口水平移动覆盖的矩形。左右手柄对称修改设定半径，数值输入同步预览；边框主体不拦截鼠标。范围按当前显示器可用区域裁剪，工具栏分别显示设定半径和实际移动距离。应用后保存，取消或 Esc 放弃；仍然只左右走动。手动拖动角色后更新中心。

「允许移出屏幕」默认关闭。开启后可手动移到屏幕外，松手、缩放和动作切换不拉回；屏幕布局相同时重启保留位置。完全移出屏幕后暂停自动走动。托盘和设置中的「找回桌宠」可恢复位置；显示器断开、布局或 DPI 改变时恢复到可见区域。

## 倍速与主题

外观与窗口提供浅色、深色、跟随系统主题，默认跟随系统。动画播放与动作过渡分别支持 0.25×～4×，默认 1×。全局值适用于所有服装，也可以分别启用当前服装的独立覆盖；关闭覆盖立即继承全局值。

播放倍速控制动作时间，眉眼、口型、光环和道具事件一起变化。组合中的指定秒数和结束间隔使用实际时间，不被倍速缩短。自动走动的步频跟随移动速度；手动试播走路片段使用播放倍速。过渡以 0.18 秒为 1×，倍数越大越快，独立于播放倍速，并保留道具缩放保护。

## 滚轮穿透

在「外观与窗口」开启「滚轮穿透桌宠」，鼠标停在角色上时滚动下层窗口，支持纵向和横向滚轮；不再缩放角色，点击互动与左键拖动仍可用。默认关闭，关闭后恢复滚轮缩放；仍可通过设置或托盘调整大小。

程序只转发自身窗口收到的滚轮消息，不移动系统鼠标、不抢焦点，也不安装全局输入钩子。辅助程序随便携包提供，按需启动，退出桌宠时一并关闭。转发遵守 Windows 窗口权限限制；不同应用的滚动响应取决于该应用。

## 开机启动与配置

通用设置的开机启动默认关闭，使用当前用户的 Windows 登录启动项；登录启动只显示桌宠和托盘。便携版登记当前 EXE 路径，启用后移到新位置并手动运行时更新路径。系统禁用的启动项保持禁用，界面显示实际状态；关闭开关移除本应用启动项。移动或删除便携目录会使旧路径不可用，需在新位置手动运行一次。

配置仍位于原用户数据目录，升级前的 v1 配置备份为 `settings.json.v1.bak`，v2 保留角色、位置、收藏及原开关，写入使用临时文件替换。开发运行默认使用项目内 `.dev-profile`；自动化验证使用独立 `BA_TEST_DATA` 目录，两者均不登记日常启动项。

本版还修复了关闭桌宠窗口或退出测试后定时器继续访问已销毁窗口、反复弹出「Object has been destroyed」的问题；存在未保存的组合时取消退出，桌宠仍继续正常运行。

本次不增加角色资源，仍为 47 位角色、110 套外观／形态、2,693 个普通动作、86 组家具互动。只对骨骼、几何、材质一致的家具片段建立共享 GLB；其他家具继续兼容独立 GLB。资源全部本地，程序无需 Node.js 或网络。

实际验证结果和未覆盖的环境见同目录「验收记录.md」。

## 0.2.3 菜单与角度

外观与窗口增加右键菜单编辑卡片：勾选显示项、上移／下移、恢复默认。角色与动作面板、退出始终可见；配置只影响桌宠右键菜单，托盘保留完整菜单。常用动作随当前服装的动作收藏变化。菜单支持搜索、方向键、Enter、Esc 和点击其他窗口关闭，颜色跟随设置主题。

顶部恢复角度只将三个旋转轴归零；找回桌宠只恢复位置。XYZ 可输入正负任意有限角度，并跨重启保存多圈角度。X 轴使用 Ctrl＋上下拖动，Y 轴使用 Shift＋左右拖动，Z 轴使用 Alt＋左右拖动。走动中保持直立，走动结束后恢复原三轴朝向。

# 0.2.9 修复与交叉检查

## 口型

- 日奈原版和泳装的原始材质均声明 4×4 图集，旧配置错误地按 8×8 寻址；现已改为 4×4，并把默认／重置格从 600 改为 300。原始动作事件和 UV 几何不变。
- 佳代子礼服、纺希的原始 MouthDefaultUV 分别为约 (0.12,0.5)、(0.38,0)。新增精确默认 UV 描述，保留默认和重置时的位置；明确指定格子的事件和翻转事件按真实格子寻址，不再残留四舍五入偏差。爱露礼服双人家具中的佳代子同步更新。
- 对照全部 149 套口型的官方材质，图集行列数全部一致。全部 149 套 UV 均在原始默认格范围内。289 个模型的浮点顶点颜色无超范围。

## 家具

- 美祢花朵茶几恢复原始两段倒茶水流与杯口涟漪。水流与动画时间同步，短倒茶主要被杯口遮挡；抬高茶壶时可见完整水流。未添加替代几何或自制贴图。
- 莉音、时武装的单人／双人电脑家具接入原始游戏画面，沿用 0.2.8 修正后的 Color32 转换，避免白色覆盖层。
- 运输船舱保持正对角度。角色在飞行片段中远离窗口是原始动画的位置变化，未篡改比例。已找到窗外云雾的原始粒子和材质，但该背景需要完整的深度遮罩、软粒子和烟雾着色器；仅加入渐变层会漏到窗框外，因此测试版本未装入正式资源。

## 验证

- TypeScript 类型检查、43 项核心测试通过；角色资源引用和原始口型事件一致性检查通过。
- 日奈原版／泳装、佳代子礼服、纺希、爱露礼服离线运行测试：待机、互动、提起各 3 个时间点，共 45 个关键帧；另检查爱露／佳代子双人家具口型纹理独立。
- 本版家具效果以冻结的原始时间点检查，避免截图时动画继续播放造成错判。Windows 免安装成品断网验证通过：5 个家具入口、23 个关键帧，以及上述 5 套服装的 45 个口型关键帧和双人家具；无需系统 Node.js。
- 30 分钟离线循环：39 轮，实测 1801.2 秒，平均 28.47 FPS，无运行错误。进程合计工作集在预热后约 774～1125 MiB；最后两个 5 分钟均值为 996.4／1009.1 MiB，通过增长阈值检查。GPU 几何体／纹理数随场景切换下降再上升，未持续累积。报告 `test-results/release029-particles-soak.json`。随后补齐少量通关图层，另做成品离线回归，不将其说成再次完成 30 分钟测试。

## 当前限制

本轮特效导出所需的原始材质与贴图依赖已全部找到，导出记录为 63 个特效根节点、0 个缺失依赖。只按 ZIP 与 UnityFS 文件头定位依赖，再下载命中的单个文件，并校验长度与 CRC。

尚未完整支持的是渲染逻辑：运输船舱窗外云雾，以及部分家具的随机烟花、朝向相机的表情粒子、连续发射和子粒子。现有 Three.js 适配器不能准确重现这些 Unity 模块，不能用替代贴图或不完整的遮罩宣称完成。主家具、角色和已列出的屏幕／水流修复正常保留。逐项记录见 `test-results/cafe-fx-adaptation.json`；这是明确待办，不是已验证无问题的项目。

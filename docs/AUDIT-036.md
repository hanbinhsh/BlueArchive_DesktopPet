# 0.2.15 家具粒子修复（2026-11-16）

本版承接 0.2.14 的修复，针对用户在 `0.2.14-final` 中再次观察到的问题重新核验。旧包的验收结果不作为本版成品测试结果。

## 本次修复

| 问题 | 处理 |
| --- | --- |
| 八云销售桌空手看手机 | 导入角色自带的原始手机粒子网格，并按五段原始动画的启用区间分别重启手机、屏幕和图标。修复重复动画的显隐曲线被后段覆盖；同类曲线修正覆盖另外6个模型。 |
| 忧行李箱、柠檬树等扩散光效盖住人物 | 使用本机 Unity 编辑器 `ParticleSystemRenderer.BakeMesh` 对比 View、Facing、Local。确认 View 的深度枢轴与 Facing 不同，修正 View 背景光被推到人物前方的问题。保留原始大小、颜色和时间。 |
| 小桃、小绿木制电视家具视角 | 默认朝向改为 1.375π，使两个角色的脸更清楚。 |
| 妃咲龙椅1反向 | 初始朝向改为 1.25π，与用户参考图核对。 |
| 艾米泳池开头波浪偏移/穿模 | Unity 原生网格粒子测量确认 Z 枢轴应与 X/Y 采用不同符号；修正源波浪约1.679模型单位的偏移。同类非零Z枢轴处理涉及12个模型。 |
| 艾米水面旋转闪烁、循环纹理跳变 | 恢复原材质深度偏移及透明层深度写入设置；水面与粒子着色器的滚动时间跨动作循环连续，暂停时仍停止。原始动画自身的水色变化及水花配色保留。 |
| 茜闸机投影光束 | 用 Unity 原生测量核验拉伸粒子的前端、横纵轴枢轴与深度处理；复测正反视角。 |
| 爱理南瓜柜台音符留在原处 | 初始速度等曲线按粒子发射时刻取样，恢复原始发射轨迹；检查子发射器继承。 |
| 街机外露扫描线 | 恢复本地对齐屏幕粒子的原始背面剔除，检查屏幕正面及背面旋转视图。 |

## 原始效果的边界

- 鹤城大型泳池的水面原本是平面。已核验原始 MX/Water 顶点程序没有水面顶点位移，片元程序没有深度折射；原始基础水色透明度约0.545。游泳圈穿过水平水面时仍会存在平直交界。本版保留原始水面和泡沫，不把人为新增的几何波浪称为官方效果。
- 艾米泳池的源动画包含水色变化，水花与常驻水面也使用不同的源材质。修复位置、重叠和循环时间错误，不强行把各层改成同一种颜色。
- 爱丽丝沙发气泡的原始粒子启用了旋转，保持该动画。粒子随机值使用稳定种子，未声称复现 Unity 私有随机序列或游戏完整灯光环境。

## 交付校验

免安装包和源码包由 `scripts/package-release036.py` 生成。脚本要求本版完整30分钟记录、145项成品回归、程序和资源哈希一致，随后检查ZIP CRC，并逐文件比较免安装ZIP内内容的SHA-256。校验结果写入 `test-results/release036.json`。

源码包包含实现、转换脚本、测试和验收记录，不重复收录原始游戏下载／Unity缓存。使用免安装包中的资源即可构建离线程序；重新从原游戏导出资源仍需要相应官方资源和转换环境。

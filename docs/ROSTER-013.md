# 0.2.18 若藻与伊吹

在0.2.17泡沫和历史反馈复核完成后追加2位角色、4套外观：若藻原版／泳装、伊吹原版／泳装。使用官方JP r96原始模型、贴图、骨骼、动画及事件。原始存档和bundle按官方目录的大小与CRC核验；不使用同人重建。

本次保存了2026-11-17的学生数据与用户指定的角色模型页面快照。网页列出若藻两套、伊吹原版；伊吹泳装另从已存在的官方CH0347资源适配。对应学生ID为10033、10043、16014、20060。数据来源及SHA256见validation/wave13-selection.json，bundle清单见wave13-acquisition.json。

若藻常服使用原始Cafe_Wakamo_Original预制体，戴面具。其MouthRenderer为空、MouthMaterialIndex=-1，保留官方表现，不生成人工嘴型。其余三套包含原始口型图集／事件；四套均带原光环和跟随参数。

新增128个普通动作。密集取景检查排除若藻泳装2个、伊吹泳装4个需原技能舞台的片段；原曲线不改为替代动作。实际开放动作数为34、30、50、14，原始曲线对应关系与排除原因记录于wave13-resources.json及wave13-framing.json。

新增5项家具互动：情人节曲奇沙发、复古音乐扩音器、一步一脚印书桌套装、单人沙浴池、与伊吕波泳装一起的双人沙浴池。伊吕波只作为该原始场景的搭档，不加入单独可选角色。沙浴片段保留原始后半段休息时间；首个互动片段约25.83秒，完整时间线约55.83秒。所有家具均逐一比较四个方向，采用人物脸部可见的斜正面默认视角。

双人沙浴的粉发头部、沙堆、帽子和周边小物已与[Yostar发布图（GameWith新闻稿转载）](https://gamewith.jp/gamedb/6253/articles/61471)核对；这些是原始场景表现。参考图片与来源摘要保留在validation/sandbath039-official-release-reference.jpg及wave13-reference.json。

5项家具的时间线特效均完成转换且无记录到的遗漏。复古扩音器的常驻音符位于原始Object_Idle分组，仅场景空闲时启用；互动使用自己的音符轨道，不把两套同时叠加。原始粒子与启用轨道来源见wave13-persistent-audit.json、activation035-source.json。

原有599个资源逐文件保持与0.2.17实测成品一致，包含本轮刚修复的鹤城、日奈泳池及美祢液体。合计154套外观、3,936个普通动作、150项家具。成品实测结果如下。

## 成品验收（2026-11-17）

82项TypeScript、26项Python测试及类型／构建／资源检查通过。128个新增动作（含4项待机）在最终免安装成品离线播放，正常重启后角色恢复；角色表情／提起36帧、5项家具50帧共7张接触表全部审阅。对比20个视角候选后选定默认朝向。四套各持续拖动23秒，窗口始终540×523逻辑像素；提起、放下与自然动作回待机均有多帧过渡。初次拖动探针被额外按下／松开事件打断，改在屏幕外、不抢焦点的隔离窗口重测全部四套后通过，未将被打断的记录记为通过。

已逐项比对新增角色67,312条原始动画通道，插值方式、时间与数值不变。静态表面源检查覆盖144个独立家具模型、265项可对应原始材质，没有同类DSFX／Tint遗漏或来源读取错误。616个离线文件与成品逐项哈希一致，其中原599个资源及15个程序运行文件与0.2.17完全相同，因此保留前轮历史问题复核证据；没有用本轮86帧冒充重新审阅所有旧动画。

最终0.2.18成品再次连续离线运行1801.644秒、33轮组合、30次角色切换，平均28.89 FPS，零捕获错误。预热后进程合计工作集792.8～1231.5 MiB，最后两个五分钟均值913.71／961.88 MiB，通过增长判据。GPU进程系统内存129.4～237.9 MiB，并非显存测量。新沙浴的单／双人完整时间线及鹤城、日奈、美祢、艾米等历史场景均在循环中覆盖。

成品目录validation提供来源、排除片段、关键截图和验收摘要；完整运行数据保留在源码工作区test-results。默认不创建程序或源码压缩包。仍以关键时刻采样与明确来源对应为验收范围，不宣称与游戏完整光照／后处理逐像素一致；原始技能演出舞台、音效等未作为新增内容。

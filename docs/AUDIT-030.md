# 0.2.10 家具贴图与粒子补全（2026-11-06）

## 本轮范围

针对 12 套原始家具时间线、63 个特效根节点，补全 22 个已安装家具入口的特效。涉及运输船舱、茜制服闸机、爱丽丝沙发与双人街机、日富美／梓赛车机、桔梗泳池、小雪睡衣桌游、小桃／绿木制游戏机和气垫球、美祢茶几、妮露／时赛车机及莉音／时武装电脑。外观和家具数量不变，未改变已有默认视角。

- 运输船舱：原始云雾纹理、三层背景、渐变、前景云朵、敲窗提示及速度线；保留原始深度遮罩，并将背景限制在原始窗洞内。云雾使用深度预绘制实现交界处淡出。
- 粒子：圆形、球形、半球、盒形、圆锥／圆锥体、边缘发射，多个 burst、固定速率发射、预热、出生／结束子粒子、速度限制、阻力、重力、旋转、尺寸、颜色、图集动画与纹理翻转。原始重力读取为 (0,-9.8100004196167,0)，来源为已缓存游戏 PhysicsManager。
- 材质：按原始着色器程序恢复云雾、像素火焰、遮罩、溶解、扭曲、分通道水流和 UV 滚动。保留第二套 UV，避免按普通颜色贴图直接显示数据纹理。
- 透明桌面适配：预乘混合对粒子透明度进行配套处理，防止已淡出的光层仍把屏幕叠白；乘法效果保留底层透明度；纯加法效果不生成不透明矩形背景。
- 修正气垫球家具根节点和名字相似的 FX 节点被判为同一绑定的问题。子粒子按触发时刻生成，不再以编辑器中的子发射器摆放位置直接播放。
- 追加源参数巡检：美祢花朵粒子接入按出生时刻旋转的圆弧发射和绕转速度，赛车机闪光接入径向扩散。两个使用不同模拟空间标记的赛车机光效，其完整父节点链均无动画变换，因此保持静态发射器绑定；不据此声称已通用支持任意移动发射器。

## 验证记录

- TypeScript 检查、48 项核心测试和全部已登记角色资源检查通过。
- 最终 Windows 成品离线回归：22 个家具入口、228 个关键帧，无加载／着色器错误；追加电脑正面、倒茶与船舱 6 个入口、27 个时刻检查。两轮记录分别为 `packaged030-runtime.json`、`packaged030-focus-runtime.json`。关键帧抽样不等于全动作逐帧验证。
- 599 个打包资源文件逐字节与工作区一致。相对 0.2.9，只有 22 个目标 GLB 改动，276 个其他 GLB 和 301 个非模型资源文件不变；22 个模型原有场景元数据完全保留，未重写默认角度或口型事件。GLB 文件数包含未登记的历史文件，界面可选资源数量以角色清单为准。
- 成品内 15 个运行文件与最终构建一致，滚轮辅助程序一致。0.25×／1×／4× 的船舱、倒茶、赛车机在相同动画时刻，粒子位置、尺寸、透明度、脸部轨道及口型 UV 一致；模拟系统休眠通知时帧计数与动画计时停止，恢复后继续。此次为通知模拟，不是本机真正休眠唤醒。
- 最终成品连续离线运行 1801.6 秒，平均 29.48 FPS，零运行错误。覆盖 38 轮组合（最后一轮在 30 分钟截止时停止）。预热后的进程合计工作集为 813～1187 MiB，最后两个 5 分钟均值为 969.6／971.7 MiB，没有出现持续增长。渲染进程 JS 堆为 77.6～92.9 MiB；Three.js 几何体／纹理数分别为 10～409／10～163，随场景切换回落，场景缓存最多 3 个。这些资源计数不是独立显存占用测量。原始记录及曲线随源码包置于 `validation/release030-final-soak.json`、`validation/release030-stability.png`。

## 精度和范围说明

本轮原始依赖无缺失，已选 22 个入口的导出器不再报告遗漏。此结论仅覆盖这些已提取时间线，不等于全游戏每一种特效都已实现，也不把其他家具的少量截图当作逐帧验收。

随机采样使用可复现的种子，以便暂停、倍速和跳转保持一致；不宣称与 Unity 的内部随机数逐位相同。速度衰减使用固定 60 Hz 数值积分，不能保证与原引擎每帧完全一致。透明桌面合成不同于游戏的不透明咖啡厅背景；本版没有移植完整场景光照、后处理泛光或相机控制脚本。

参数语义参考：[Unity 速度模块](https://docs.unity.cn/Manual/PartSysVelOverLifeModule.html)、[圆弧发射速度](https://docs.unity3d.com/ru/2020.2/ScriptReference/ParticleSystem.ShapeModule-arcSpeed.html)。材质参数、图像、发射曲线和时间线均来自本地缓存的原始资源。

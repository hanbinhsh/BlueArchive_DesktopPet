## 来源、修复与适配说明

- 随机 4 位学生按保存的 SchaleDB 日服已实装学生名单按身份合并服装抽取，种子与候选池见 `test-results/wave18-selection.json`。
- 探索模式拆分家具来自官方 `field-cafe-_mxload-prefabs-2025-07-02` / `2026-04-27` 独立预制体与 `field-cafe-_mxdependency-timelines-*` 原版时间线；按原版 `clipIn` 与 `duration` 精确切片，剥离虚拟相机镜头遮罩（`VC_Field_843_Zone01_Mic/FX_DM/Fade*`），并通过 `restore_geometry` 还原纯刚体网格（钢琴、公园长椅）。
- 修正 `scripts/visibility.py` 中 `ignored_events` 的判定顺序，确保明确忽略的旧版战斗渲染器事件即使索引与光环节点重合也不会错误关闭光环；由此安全恢复 `toki` 全部 20 段原版动作（总计 25 段，0 遗漏）。
- 修正日鞠原版（`CH0159`）渲染器事件索引映射（`3 -> CH0159_Blanket_Mesh`），避免编队提起时误隐光环而非腿毯；处理真琴泳装（`CH0344`）4×4 口型图集负偏移默认值与 `Clamp` 采样兼容，还原全部口型切换事件。
- 补齐 8 项咖啡厅家具原版特效（含莲华古风料理台角色内嵌表情粒子）；10 套新外观与全部 20 组新家具均通过 90,472 条原版骨骼通道一致性校验与四向实机截图复核，并配置正面默认视角。
- 本版默认仅交付可运行文件夹（`release/v0.2.27/win-unpacked/BA Desktop Pet.exe`），不创建 ZIP 压缩包。

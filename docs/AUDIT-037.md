# 0.2.16 家具显示与粒子时序修复（2026-11-17）

本轮重新处理0.2.15实测反馈，并检查新增参考图及用户提供的艾米本地视频。旧版本通过的测试不代表这些视觉问题已经解决。

## 修复

- 爱理南瓜柜台：恢复原始隐藏的两个触发发射器。它们继续模拟并触发真正音符，但自身不再画出从上方飞向角色的一组音符。同类检查涉及9个模型、58个辅助粒子。
- 茜闸机：原始HUD_Pos自身Renderer关闭，只用于承载子层。保留子投影、图标和光束，去掉被误画在闸机内的辅助面。
- 八云销售桌：恢复原始CH0228_Prop03_Outline实体手机，不再只显示平面光效。原网格带厚度和机身贴图；屏幕效果继续按原始五段时序播放。对本家具修正旧编号显隐事件对实体手机的错误关闭。
- 鹤城泳池：恢复泡沫遮罩图集的原始sRGB采样，其余水纹数据纹理保持线性；隐藏原本不显示的辅助Renderer。上一版仅凭水平水面判断视觉正确的结论撤回。水面几何仍为源平面，泡沫和透明度须一起核对。
- 宫子淋浴：按Unity原生BakeMesh确认网格粒子完整三轴旋转与相机变换的顺序，喷水向下。补齐水平公告板模式的地面水花；在透明桌面缺少游戏地面遮挡时，按底座接水面裁切水流，避免穿过底座继续显示。
- 兔女郎花凛：CH0100_Table_02源着色器为MX/C-Simple-Transparent，恢复玻璃杯透明材质，保留原液体颜色和几何。
- 礼服佳代子：补入家具预制体上常驻的13个原始蜡烛特效根。
- 佳代子／爱露高级要员书桌：补入常驻蒸汽。缺失纹理通过已有官方目录定位单一bundle，远端ZIP范围读取并校验尺寸、CRC，未下载整库。
- 宫子露营椅：原始短速度曲线使用Loop模式，修正此前全部当成Clamp的解析错误，恢复轮流上升和停留。同步支持PingPong，原延迟、寿命、颜色保留。
- 艾米泳池：恢复特效内部11条ControlPlayable窗口及clipIn，主波浪在16.7秒开始，材质Recorded曲线继续使用外层时钟。已按用户要求截取本地视频关键帧，与企鹅回岸过程对照。源码validation保留控制窗口记录。
- 旧版水纹材质改为独立公式，依据原始D3D程序处理遮罩、透明度和旧参数名。
- 同类排查发现游戏开发部电脑家具也遗漏了内部启用时间线：补回4个场景的240个Activation／Control窗口和132条变换曲线。按原始对象ID区分同名兄弟节点；启用窗口以同一内部导演时钟求交，不把父片段的clipIn误当成下一条轨道的起点。
- 进一步扫描106个家具预制体，补回心奈茶杯蒸汽、泳装梓家具微光、小雪抓娃娃机灯效、小桃／小绿空气曲棍球灯效和露营真纪展板的原始常驻粒子，涉及6个模型。保留互动时关闭的Object_Idle专用节点；最终扫描没有无法解释的常驻粒子遗漏。
- 常量寿命的连续发射与爆发共用原始maxNumParticles上限。小雪灯效原为1个粒子槽，不再把每秒120次发射都转换为重叠图层；不改原发射率、贴图或寿命。

## 验证与交付

82项TypeScript测试、24项Python测试、类型检查与资源检查通过，包含隐藏发射器仍触发子粒子、Unity原生曲线循环、嵌套窗口剪裁和独立时钟回归。原生探针记录在test-results/unity037-rotation.txt，源码为RotationProbe.cs。27项资源变更前备份在.assets/pre037，安装脚本逐项比较人物和家具基础几何。

暂存画面已检查玻璃液体、蜡烛、蒸汽、气泡、手机、喷头方向、脚边水花及波浪关键时刻。临时红色／通道诊断、实验高度和深度覆盖已移除，不进入成品。

实际成品离线遍历145个家具入口、435张关键帧，15页接触表已逐页查看。后续只改10个模型，程序app.asar和其余资源不变；游戏开发部4个场景另补20张成品关键帧，6个常驻粒子场景另补18张，均已复测查看。重点场景另检查43张成品截图，艾米3次循环与模拟暂停／恢复测试通过。

艾米原视频已截取全段概览和17.5～21.5秒的回岸过程；源码包validation收录这两张接触表。原视频本身包含绿色、黄色、蓝色水面灯效，此处不擅自改成固定蓝色。宫子地面水花按原始位置和透明度保留，间歇出现，未改成常驻不透明水面。

最终成品断网连续运行1801.496秒，完成48轮组合、46次角色切换；46次窗口重载均对应角色切换，无额外重载，零捕获错误，平均29.46 FPS。此前为增加6个模型主动结束的阶段长测没有计入这次结果。

预热后进程合计工作集754.86～1566.38 MiB；倒数第二个五分钟均值916.51 MiB，最后五分钟886.78 MiB，通过既定增长判据（末段均值≤前段均值×1.15＋30 MiB）。缓存最多2个场景；采样时活跃几何／贴图峰值分别131／122。GPU进程工作集134.00～244.50 MiB为系统内存，不是显存测量。详细逐场景资源数见validation/release037-resource-summary.json。

测试前锁定可执行文件、app.asar及599个离线资源哈希；打包脚本要求这些内容与验收版本一致，生成ZIP后检查CRC及包内逐文件SHA-256。源码包包含转换脚本、测试和验收证据；构建时从免安装包复制resources/characters及滚轮转发器，无需重复下载游戏。

游戏完整灯光、背景折射及Unity私有随机序列不作逐位复现保证；采样检查不等于所有动画逐帧验收，有限时长长测不代表无限运行无泄漏。本轮不包含真实登录启动、物理多屏拔插测试。

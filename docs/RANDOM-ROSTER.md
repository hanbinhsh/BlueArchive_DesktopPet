## 来源与范围

随机候选与服装名单来自 https://schaledb.com/data/en/students.json 及对应中文数据；抽签种子、候选名单、原始数据哈希保存在 `validation/wave11-selection.json`。模型、贴图、骨骼、动作、口型事件和光环参数来自游戏官方 Windows 补丁资源，按目标角色下载并检查 CRC，再转换为内嵌贴图的 GLB，运行无需联网。

新增角色沿用游戏中的原始动作，包含待机、互动、提起及可绑定到本体的其他动作。花凛原版与莲见原版各有两个 TSS 片段依赖配套场景，未作为独立动作加入；本批未新增家具场景，也未移植音效、粒子或完整技能镜头。这里的动作数指可播放的人物骨骼／道具动画，不代表完整游戏技能演出。

## 使用

退出旧版桌宠后，解压并运行 `BA Desktop Pet.exe`。在“角色与动作”中搜索角色名；角色标题旁的星标收藏整个人物，可从“角色收藏夹”查看。动作排序和动作收藏继续沿用上一版本设置。无需安装 Node.js。

源码包不重复包含模型；构建时将同版免安装包的 `resources/characters` 复制到源码根目录，详见 `docs/BUILD.md`。
